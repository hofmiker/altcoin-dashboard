MVRV Quantile Bands

Methodik, Formeln & Datenquelle Details anzeigen

MVRV = Market Cap ÷ Realized Cap. Realized Cap bewertet jedes UTXO zum Preis seiner letzten Bewegung statt zum aktuellen Kurs — eine Art durchschnittlicher On-Chain-Einstandspreis. MVRV > 1 → Markt im Schnitt im Gewinn, MVRV < 1 → im Schnitt im Verlust.

Realized Price = Realized Cap ÷ Circulating Supply = Marktpreis ÷ MVRV.

Quantile Bands: An jedem Tag t werden die erweiternden Perzentile (5/25/50/75/95 %) aller MVRV-Werte von Beginn der Historie bis t berechnet — keine fixen, sondern mit der Zeit präziser werdende Bänder. Jedes Perzentil wird über Band-Preis(t) = Realized Price(t) × Perzentil-MVRV(t) zurück in eine Preislinie umgerechnet.

NUPL (Net Unrealized Profit/Loss) = (Market Cap − Realized Cap) ÷ Market Cap = 1 − 1/MVRV. Anteil des Netzwerks, der aktuell im nicht realisierten Gewinn sitzt.

MVRV Z-Score = (Market Cap − Realized Cap) ÷ Standardabweichung(Market Cap), Standardabweichung erweiternd über die gesamte bisherige Historie berechnet. Filtert MVRV-Extremwerte relativ zur historischen Volatilität.

MVRV-Perzentil: Rang der aktuellen MVRV-Ratio unter allen bisherigen MVRV-Werten (0–100 %), ebenfalls erweiternd berechnet — unabhängig von der absoluten MVRV-Skala und direkt vergleichbar mit den Quantile-Bands-Zonen oben.

Eigene Annäherung an das Konzept (u. a. bekannt von bitcoinmagazinepro.com / LookIntoBitcoin), keine 1:1-Kopie proprietärer Charts. Zonen-Schwellenwerte (Kapitulation/Euphorie etc.) sind gängige Näherungswerte, keine exakten Grenzen. Die ersten rund zwei Handelswochen ab 2010-07-18 sind aus der gesamten Datenreihe entfernt: Realized Cap war zu dem Zeitpunkt mangels bewegter Coins praktisch bei null, was die MVRV kurzzeitig auf über das 140-fache trieb — ein Methodik-Artefakt, kein reales Marktgeschehen.

Datenquelle: Coin Metrics Community API — kostenlos, kein API-Key. Angefragt werden PriceUSD, CapMVRVCur, CapRealUSD, SplyCur, CapMrktCurUSD; welche davon Coin Metrics ohne Zugangsdaten tatsächlich herausgibt, kann sich ändern (bestätigt: CapRealUSD liefert aktuell "not available with supplied credentials"). Der tägliche Abruf-Job testet das bei jedem Lauf einzeln pro Metrik und verwendet nur, was wirklich freigegeben ist — Kennzahlen, die das nicht mehr abdeckt, werden auf der Seite ehrlich als "nicht verfügbar" markiert statt geschätzt.

Coin Metrics erlaubt zwar direkte Navigation zur API-URL, blockiert aber Cross-Origin-fetch()-Aufrufe aus dem Browser einer fremden Domain wie dieser GitHub-Pages-Seite. Ein direkter Live-Abruf wird deshalb zwar versucht, schlägt aber in der Praxis meist fehl. Die eigentliche Datenquelle ist ein täglicher, unveränderter Snapshot (data/mvrv/latest.json), den eine GitHub Action serverseitig per curl von derselben API holt und mit Datum versieht. Welche Quelle gerade aktiv ist und wann sie abgeholt wurde, steht immer oben im Status-Banner.

Nur zu Informationszwecken, keine Anlageberatung. Historische Bewertungszonen sind kein Indikator für zukünftige Kursverläufe. Daten: Coin Metrics Community API (frei zugänglich, ~15 Min. Verzögerung).
