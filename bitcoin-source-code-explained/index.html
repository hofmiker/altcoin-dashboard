CBlock::CheckBlock()

main.cpp, Zeilen 1154–1190
main.cpp
Testausschnitt: aktuell ist nur diese eine Funktion aufbereitet. Die grau hinterlegten Zeilen (Signatur, return true;, Klammern) sind nicht anklickbar — klicke auf einen der hervorgehobenen Codeblöcke, um ihn rechts erklärt zu bekommen.

Wie viel vom Original-Code lässt sich so aufbereiten?

main.cpp (v0.1.0) hat 2.660 Zeilen. Grob geschätzt:

~18 % Kernalgorithmen — gut visualisierbar (CheckBlock, BuildMerkleTree, BitcoinMiner-Schleife, CheckTransaction/ConnectInputs, Coinbase-Reward) ~27 % Netzwerk/Wallet-Logik — erklärbar, aber eher Ablauf- als Konzept-Diagramme (AddToWallet, Sync, IRC-Peer-Discovery) ~55 % Plumbing — Windows-GUI (ui.cpp/uibase.cpp), Datenbank-Boilerplate, Serialisierung: für's Verständnis des Whitepapers uninteressant

So funktioniert's: Klicke links auf einen hervorgehobenen Codeblock — hier erscheint dann in einfachen Worten, was er tut und warum, teils mit eigenem Schaubild.

Diese Funktion, CBlock::CheckBlock(), ist die Torwächter-Prüfung: Jeder neue Block muss sie bestehen, bevor ein Knoten ihn überhaupt akzeptiert.
