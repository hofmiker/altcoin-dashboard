# altcoin-dashboard

`index.html` ist eine Übersichtsseite mit Kacheln zu allen Dashboards unten.

## Dashboards

- [Pump-Signal-Dashboard](altcoin-dashboard/index.html) — tägliche Altcoin-Kandidaten-Scans.
- [Bitcoin On-Chain Dashboard](btc/index.html) — Live-Kurs & Netzwerk-Metriken.
- [Bitcoin 3D](bitcoin-3d/index.html) — 3D Candlestick-Visualisierung.
- [MVRV Quantile Bands & On-Chain-Dashboard](mvrv-dashboard/index.html) — Bitcoin-Bewertung (MVRV, NUPL, Z-Score, Realized Price u. a.) live via Coin Metrics Community API, mit Kacheln- und Überlagerungs-Ansicht.
- [Bitcoin-Whitepaper Erklärt](bitcoin-whitepaper-explained/index.html) — das Original-Whitepaper zum Durchscrollen, jeder Absatz klickbar mit einfacher Erklärung & Schaubild.
